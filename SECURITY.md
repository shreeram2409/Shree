# Security Lab Rules

This project is for learning and defensive testing only.

- Run it locally in your Codespace.
- Only test systems you own or have explicit permission to assess.
- Do not use this project to access, disrupt, or extract data from third-party systems.
- Keep real passwords, tokens, API keys, and personal data out of the repository.

## Learning path

1. Input validation
2. Output encoding
3. Authentication design
4. Security headers
5. Add tests for each defense

For real-world work, use an authorized training platform or a dedicated test environment.
